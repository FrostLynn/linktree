# frostlynn.github.io

A personal link-in-bio page for **Akhdan Rafif Nugraha** — built with a **neo brutalism** design style.

## Preview

Visit the live site: [frostlynn.github.io](https://frostlynn.github.io)

## Features

- **Neo Brutalism UI** — bold borders, solid offset shadows, bright accent colours, monospace typography
- **Profile popup** — click the profile picture to view a quote overlay
- **Social links** — Github, LinkedIn, Facebook, Instagram, Twitter, Threads, Steam, and more
- **Background music** — autoplays with a toggle button (graceful fallback if the browser blocks autoplay)
- **Responsive** — works on mobile and desktop

## Tech Stack

- HTML5
- CSS3 (custom properties, flexbox)
- [Font Awesome 6](https://fontawesome.com/) for icons
- [Space Mono](https://fonts.google.com/specimen/Space+Mono) font via Google Fonts


## Getting Started

No build step required. Simply open `index.html` in a browser or deploy to any static hosting (GitHub Pages, Netlify, Vercel, etc.).

```bash
# Clone the repo
git clone https://github.com/FrostLynn/frostlynn.github.io.git
cd frostlynn.github.io

# Open in browser
open index.html
```
